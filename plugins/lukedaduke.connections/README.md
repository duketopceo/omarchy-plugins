# Connections (retired)

This plugin is retired. It is replaced by Omarchy's built-in Bluetooth (`omarchy.bluetooth`) and Network (`omarchy.network`) bar widgets.

## Move to the replacement

1. Add `omarchy.bluetooth` and `omarchy.network` to your bar from Omarchy's bar settings (they ship with Omarchy).
2. Remove this plugin: `omarchy plugin remove lukedaduke.connections` (or delete `~/.config/omarchy/plugins/lukedaduke.connections`).

This final release (3.0.0) only shows a dimmed icon whose tooltip points to the replacement.
It runs no helpers and makes no network calls. The repository is archived after this release.
