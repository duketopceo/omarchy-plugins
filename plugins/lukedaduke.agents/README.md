# My Agents (retired)

This plugin is retired. It is replaced by `akitaonrails.ai-usagebar`, which covers more AI providers.

## Move to the replacement

1. Install it with `omarchy plugin add` from the Omarchy plugin marketplace (search "ai usage"), then place `akitaonrails.ai-usagebar` on your bar. Omarchy's built-in `omarchy.agents` is another option.
2. Remove this plugin: `omarchy plugin remove lukedaduke.agents` (or delete `~/.config/omarchy/plugins/lukedaduke.agents`).

This final release (3.0.0) only shows a dimmed icon whose tooltip points to the replacement.
It runs no helpers and makes no network calls. The repository is archived after this release.
