# lukedaduke.ticker

Omarchy bar widget for a fixed watchlist (gold, tech, nuclear, energy, rates).

Quotes come from Yahoo chart endpoints. Failed rows show `--`. The panel keeps the last good snapshot when the whole fetch fails.

```
j / k   move
Enter   open TradingView
Esc     close
```

Hardcoded M2 figures from the previous helper were removed (unverified).
